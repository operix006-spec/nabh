# 🧠 منصة نَبِـه للتدريب والتقييم الإدراكي | Nabh Cognitive Platform

> منصة عصبية إدراكية متقدمة لقياس وتدريب 50 مهارة ذهنية عبر 14 محرك ألعاب تفاعلي، مدعومة بنظام مصادقة متكامل وصلاحيات إدارية حصرية للمالك (Super Admin Owner).

---

## 🚀 المميزات الرئيسية (Core Features)

- **نظام مصادقة أمني متكامل (Complete Authentication)**:
  - تسجيل الدخول والاشتراك والتحقق من البريد الإلكتروني.
  - استعادة وتعيين كلمة المرور، إدارة الجلسات وميزة تذكرني.
  - دعم الدخول عبر Google ومسار زائر (Guest).
- **لوحة إدارة المالك الحصرية (Owner Administration - `mocvskhfssr@gmail.com`)**:
  - حساب المالك الوحيد المحمي بنظام RLS بقاعدة البيانات ومحمي من التعديل أو الحذف.
  - إدارة المستخدمين والصلاحيات والترقيات.
  - الإعدادات الأمنية المتقدمة وسجلات التدقيق (Audit Logs).
  - إدارة 14 محرك ألعاب وتذاكر الدعم الفني.
- **14 لعبة إدراكية تفاعلية مدمجة**:
  - ألغاز ثلاثية الأبعاد، مطابقة الألوان (Stroop)، التمييز البصري، إدراك الأنماط، ومصفوفات الذاكرة.
- **أحدث التقنيات**:
  - Next.js 15, TypeScript, TailwindCSS, Supabase (Auth & PostgreSQL RLS), Lucide Icons, Canvas Confetti.

## 🛠️ التشغيل السريع (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
